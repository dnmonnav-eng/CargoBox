## Descripción del Proyecto
**CargoBox** es una solución de software orientada a la gestión de envíos, paquetería y trazabilidad logística a nivel local y nacional. Este repositorio contiene el **diseño arquitectural formal** de la solución, traduciendo el análisis de negocio de la Unidad 2 en una arquitectura robusta basada en **Domain-Driven Design (DDD)**, el patrón de diseño **Domain Model**, una capa de aplicación desacoplada (*Service Layer*), persistencia mediante *Repository* y *Unit of Work*, y un enfoque de *CQRS básico* para comandos y consultas.
